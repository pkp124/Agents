# Example Requirements: Traceability Demonstration

## Context
This is a minimal example used to demonstrate requirement↔design↔test traceability automation.

## Requirements

### REQ-0001: Provide a traceability check command
- **Statement**: The repository shall provide an automated check that verifies requirement traceability to both design and tests.
- **Rationale**: Prevents requirements from becoming stale and ensures verification artifacts exist.
- **Verification**: Test (run the checker in CI)
- **Priority**: Must
